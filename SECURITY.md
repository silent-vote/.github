# Security & Anonymous Reporting Policy

## Reporting Vulnerabilities
If you discover a security vulnerability or data leak in any SilentVote repository, please report it confidentially. 

* **Do NOT** open a public GitHub issue for security vulnerabilities.

## Whistleblower & Data Contributor Protection
* We collect minimal metadata on data submissions.
* Never upload personally identifiable information (PII) of individual non-executive employees or victims without explicit redaction.
* All public datasets strictly mirror publicly accessible government, legal, or administrative records.
